Diagnóstico inicial

No tiene calificación. Responde con explicación y marca dónde tienes dudas.

  1. ¿Qué diferencia existe entre una base de datos y un DBMS?
  2. ¿Qué protege una clave foránea?
  3. ¿Por qué NULL = NULL no funciona como una igualdad ordinaria en SQL?
  4. ¿Qué problema resuelve una transacción?
  5. ¿Cuándo un índice puede empeorar el sistema?
  6. ¿Qué diferencia hay entre respaldo y réplica?
  7. ¿Qué significa que una consulta sea idempotente?
  8. ¿Dónde se valida el esquema en una base documental?
  9. ¿Qué es una partición de red?
  10. ¿Qué mide recall@k en recuperación?

Práctica

Diseña tres tablas para estudiantes, cursos y matrículas. Escribe una consulta que liste estudiantes por curso y explica cómo impedir duplicados.

Uso del resultado

  • 0–3 respuestas sólidas: comenzar en módulo 00;
  • 4–6: comenzar en módulo 01 y realizar refuerzo SQL;
  • 7–8: prueba de transferencia de módulos 01–03;
  • 9–10: iniciar ruta avanzada, sin omitir seguridad y restauración.
