# Laboratorio 02 — Modelado políglota

## Pregunta

¿Cómo cambia el modelo de la plataforma educativa cuando la unidad de consistencia es una tabla, un documento o un subgrafo?

## Actividad

1. Lee el modelo relacional de `reference-data/school/`.
2. Inspecciona `course-document.example.json`.
3. Inspecciona `learning-graph.example.cypher`.
4. Escribe cinco patrones de acceso.
5. Marca qué enfoque requiere joins, duplicación o recorridos.
6. Diseña una actualización concurrente y el riesgo de cada modelo.

## Criterio

No se busca coronar un ganador. La evidencia debe conectar forma del modelo, frecuencia de cambio, cardinalidad y garantías.
