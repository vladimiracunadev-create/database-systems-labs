# Laboratorio 01 — SQL foundations

Duración: 90 minutos. Dependencia: Python 3.11+.

## Propósito

Construir y consultar una base educativa en memoria, observando restricciones, agregaciones, joins y ventanas.

## Ejecución

```bash
python labs/01-sql-foundations/run_lab.py
```

El script no crea archivos persistentes. Debe terminar con `LAB_OK`.

## Secuencia

1. Lee el dominio y predice las filas de cada consulta.
2. Ejecuta el laboratorio.
3. Completa `exercises.md` sin mirar `solution.sql`.
4. Agrega un caso límite a los datos en memoria.
5. Explica qué restricción falta para impedir una entrega de un estudiante no matriculado.

## Limpieza

No es necesaria: SQLite se ejecuta en memoria y el proceso descarta los datos.
